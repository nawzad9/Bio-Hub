How to install on iPhone & Android

Install as an app

Once installed it opens full-screen from your home screen and works without internet.

  1. 1Open this page in Safari (it must be Safari — Chrome on iPhone cannot install apps).
  2. 2Tap the Share button at the bottom of the screen.
  3. 3Scroll down and choose Add to Home Screen.
  4. 4Tap Add. The Bio-HuB icon appears on your home screen.
Tip: open each app inside Bio-HuB once while you have internet, then install it the same way — iPhone keeps every app offline separately.
  1. 1Open this page in Chrome.
  2. 2Tap the Install button above, or the ⋮ menu in the top-right.
  3. 3Choose Install app / Add to Home screen, then confirm.
  4. 4Bio-HuB is added to your app drawer like a normal app.
If the Install button does nothing, the app is already installed — check your home screen.
